## Cosa traduce

- Dialoghi, battute del giocatore e opzioni di conversazione
- Nomi di quadri, oggetti, inventario e punti interattivi
- Menu principale, pausa, impostazioni, salvataggi e legende dei controlli
- Verbi del cursore (Guarda, Usa, Parla con…), schermata Extra e commenti

I nomi dei personaggi sono rimasti in inglese (Heavenly Peter, Immortal John, Pie King, Sad Man, Beautiful Woman…).

Il pacchetto **non contiene file del gioco**: è un piccolo programma che legge i *tuoi* file originali e vi scrive le frasi in italiano.

## Requisiti

1. The Procession to Calvary installato da Steam, **versione 1.2**
2. [Python 3.9+](https://www.python.org/downloads/) (durante l'installazione spunta *Add python.exe to PATH*)
3. Connessione a Internet (una volta sola, per scaricare UnityPy)
4. Circa 600 MB liberi su disco (backup dei file originali + file nuovi)

## Installazione

1. Chiudi il gioco.
2. Estrai lo zip in una cartella qualsiasi.
3. Doppio clic su `INSTALLA_TRADUZIONE.bat` e attendi (di solito 5–15 minuti; vengono riscritti 57 file).
4. Avvia il gioco in **inglese** (è la lingua predefinita): i testi compariranno in italiano.

I file originali vengono salvati prima in `...\The Procession to Calvary\Backup_originali_ITA`.

## Tornare all'inglese

- Doppio clic su `RIPRISTINA_ORIGINALI.bat`, oppure
- Steam → tasto destro sul gioco → *Proprietà* → *File installati* → *Verifica l'integrità dei file di gioco*.

## Aggiornamenti di Steam

Se Steam aggiorna il gioco, i file tradotti possono essere sostituiti. Per evitarlo: *Proprietà → Aggiornamenti → "Aggiorna questo gioco solo quando lo avvio"* e avvia il gioco da `The Procession to Calvary.exe`. Se succede comunque, rilancia `INSTALLA_TRADUZIONE.bat`.

## Limiti noti

- Il gioco non ha una voce "Italiano" nel selettore lingua: la traduzione sostituisce i testi della lingua inglese.
- Restano in inglese: "Fullscreen", l'etichetta della lingua, "Instructions"/"Settings" in alcuni punti del menu di pausa, i nomi degli artisti nei crediti e qualche scritta interna.
- Il gioco non è stato rigiocato per intero: se trovi un testo storto o ancora in inglese, apri una *Issue* qui su GitHub indicando la frase.

## English summary

Unofficial Italian translation for *The Procession to Calvary* (Steam, Windows, v1.2). The package contains **no game files**: it is a small Python patcher that rewrites the text in *your own* game files (a backup is made first).
Download the zip from the [latest release](../../releases/latest), extract it, run `INSTALLA_TRADUZIONE.bat` with the game closed, then start the game with the **English** language selected. Use `RIPRISTINA_ORIGINALI.bat` or Steam's *Verify integrity of game files* to go back. Requires Python 3.9+.
